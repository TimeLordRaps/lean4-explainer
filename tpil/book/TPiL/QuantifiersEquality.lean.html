  38. def divides_trans Divisibility is transitive, so calc can chain it line 571 source
    Annotation provenance. This overlay contains 8 curated AI-written annotations and 121 mechanical source-derived annotations.     Compose the two witnesses by multiplying them, which is the witness for the combined divisibility.

    1. divides x y is defined as ∃ k, k*x = y.
    2. let ⟨k₁, d₁⟩ := h₁ and let ⟨k₂, d₂⟩ := h₂ unpack the two witnesses and their equations.
    3. The new witness is k₁ * k₂, and the equation is proved by rewriting with Nat.mul_comm, Nat.mul_assoc, d₁ and d₂.
    4. The book uses it to build instance Trans divides divides divides, which teaches calc about this relation.

    See also: divides_mul
