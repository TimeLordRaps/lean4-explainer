    Source comment

    L4DEL explanation

    Weekday has seven constructors, so match gives seven cases, each true by computation.

    1. Weekday is an inductive type with constructors sunday through saturday, and next and previous move one day forward and back.
    2. theorem next_previous (d : Weekday) : next (previous d) = d is proved with match d with.
    3. In each of the seven cases the two sides reduce to the same constructor, so the proof is rfl.
    4. The book follows this with a shorter version of the proof.

  64. theorem Weekday.Weekday.add_comm First attempt at commutativity of Nat addition (contains sorry) sorry line 1105 source

    L4DEL explanation

    Induct on the second argument; one equation in the step is not yet proved and is left as sorry.

    1. This is a work-in-progress block in the book: the last calc step ends with := sorry, so Lean accepts it only with a warning.
    2. Nat.recOn with motive fun x => m + x = x + m does induction on n; the base case m + 0 = 0 + m is proved with Nat.zero_add and Nat.add_zero.
    3. In the inductive step a calc rewrites m + succ n to succ (m + n), then to succ (n + m) using the induction hypothesis.
    4. The missing step succ (n + m) = succ n + m is what the book proves next as succ_add, then plugs in to replace the sorry.

    See also: Weekday.Weekday.succ_add
