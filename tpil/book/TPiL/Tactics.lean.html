  48. def swap_pair Tactics can define data: swapping a pair line 786 source
    Annotation provenance. AI-generated and not human-reviewed. Treat this explanatory draft as unverified and not mathematical authority.

    The same tactic script that proves p and q implies q and p also builds a function that swaps the two components of a pair.

    1. The type is α × β → β × α, a function type for products.
    2. intro p introduces the argument; cases p splits the pair into its two components.
    3. constructor <;> assumption builds the new pair, and for each of its two parts assumption finds the matching component in the context.
    4. The book remarks that, up to variable names, this is identical to the proof for conjunction.

    See also: swap_sum

  49. def swap_sum Swapping the two sides of a sum type line 791 source
    Annotation provenance. AI-generated and not human-reviewed. Treat this explanatory draft as unverified and not mathematical authority.

    cases splits on which side of the sum we are in, and each branch rebuilds the value on the opposite side.

    1. The type is Sum α β → Sum β α.
    2. intro p and cases p give one goal per constructor of Sum.
    3. In the first branch apply Sum.inr; assumption wraps the left value on the right; in the second, apply Sum.inl; assumption does the reverse.
    4. The book remarks that this matches the proof of commutativity of disjunction.

    See also: swap_pair

    Sources and attribution: Pinned Lean source (4e28129fdd58), Pinned Theorem Proving in Lean documentation, Pinned Theorem Proving in Lean 4 book index
