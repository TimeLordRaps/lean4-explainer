    Ordered stack matching, with unpaired positions allowed. The skipped positions will be endpoints of the other colour in the map tour.

    inductive Arches : List α → List (α × α) → Prop
  | nil : Arches [] []
  | skip (a : α) {l E} : Arches l E → Arches (a :: l) E
  | pair (a b : α) {L R E F} : Arches L E → Arches R F →
      Arches (a :: (L ++ b :: R)) ((a,b) :: (E ++ F))
