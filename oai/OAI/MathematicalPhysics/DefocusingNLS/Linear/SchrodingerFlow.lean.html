The linear Schrödinger group on the Fourier Sobolev model

Multiplication of each frequency by exp(-i t |n|²) defines a strongly continuous unitary group. The same coefficient model is used for every Sobolev index, so these isometries act on the paper's weighted Fourier spaces.
