A lattice vector off all coordinate hyperplanes

For a matrix with nonzero determinant, use the integer coefficient vector (1,N,...,N^(n-1)). Each coordinate of its row product is a nonzero polynomial in N. Finitely many polynomials exclude only finitely many integers, so a suitable integer N exists. This gives the vector selection used to deduce ordinary ball bounds from vector-box counts.
