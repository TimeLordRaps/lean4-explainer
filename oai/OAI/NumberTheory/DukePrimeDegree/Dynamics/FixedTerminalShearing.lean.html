A fixed terminal fraction for every eventual shearing limit

The fraction is chosen using only the fixed displacement scale, the compact set of possible limits and the finite test family. It does not shrink along the sequence. Hence a previously chosen generic set gives valid control at the pair-dependent stopping times.
