Uniform generic sets for bounded observables

The maximal estimate is applied to the small L1 residual of a single finite orbit average. The complementary part is an explicit bounded coboundary. Consequently one fixed set controls every sufficiently large averaging length, including lengths chosen from a nearby pair.
