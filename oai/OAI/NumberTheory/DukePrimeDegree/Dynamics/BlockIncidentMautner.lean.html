A block-fixed observable is fixed along incident invariant roots

A root touching a nontrivial special linear block has nonzero weight for some diagonal inside that block. Mautner therefore fixes that root on every block-fixed vector, provided the root already acts isometrically. The lattice corollary uses only roots in the actual measure stabilizer. It does not infer invariance under a missing reverse root.
