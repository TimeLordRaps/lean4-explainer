Bounded diagonal returns in a root centralizer

A matrix centralizing one root can have entries outside the opposite-root centralizer only in expanding directions of a suitable diagonal flow. Bounded conjugates along arbitrarily late times therefore centralize both roots. This is the matrix step in EKL (2006), Lemma 4.2.
