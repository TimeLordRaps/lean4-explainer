Transverse representatives using only a single root block

On an ergodic component for a single root block, an arbitrary ambient diagonal correction need not preserve the component measure. Here the correction is a product of roots in that block. It clears the entries inside the block and equalizes its diagonal, leaving the complementary coordinates unrestricted.
