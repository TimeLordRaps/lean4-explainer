A positive-mass block orbit from actual root ergodicity

Local block preservation of the measure stabilizer supplies the fixed transverse shell. Haar patches supply the common corrections, and root ergodicity supplies a common generic set. If every block orbit were null, the resulting normalized transverse pairs would contradict the fixed-window shearing estimate.
