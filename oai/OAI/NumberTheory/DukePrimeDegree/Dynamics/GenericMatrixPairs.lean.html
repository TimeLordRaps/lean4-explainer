Small matrix lifts of generic pairs outside a subgroup orbit

If all subgroup orbits are null, a positive-mass generic set contains arbitrarily close pairs from different orbits. Openness of the actual quotient orbit map lifts these pairs to matrices tending to identity, all outside the subgroup. This is a concrete input to polynomial shearing, without a homogeneous-orbit assumption.
