An actual ergodic root flow on a single block component

For a fixed coordinate block, the group generated by its root groups has the same invariant measurable sets as any one of its nontrivial root flows. The Mautner argument proves this for the actual lattice action. The coordinate block is not required to be the whole ambient space.
