A generic finite root orbit has a commutative stabilizer centralizer

One invariant root forces one column of every centralizing matrix to be scalar. In the rational centralizer, evaluation in that column is faithful by genericity of the actual lattice. Rational centralizing matrices therefore commute, and scalar extension gives the same result for the real centralizer. This removes any need to exclude singleton blocks before treating the larger homogeneous orbit group.
