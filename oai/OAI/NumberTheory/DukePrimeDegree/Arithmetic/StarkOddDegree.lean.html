Odd-degree descent for real cyclic zero characters

For the application to Stark's argument it is enough to know the restrictions of the zero character to cyclic subgroups. A real class function with these restrictions and average one on an odd-index subgroup is identically one. The proof uses a Sylow two-subgroup acting on the odd set of cosets; it does not require a global Artin character.
