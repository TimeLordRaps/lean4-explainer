A scalar double block in an integral return matrix

The centralizer of the root SL₂ has a scalar two-dimensional block. The remaining block in a sufficiently separated return has simple real spectrum. Such a return matrix cannot be conjugate to an integral special-linear matrix unless the scalar eigenvalue is ±1.
