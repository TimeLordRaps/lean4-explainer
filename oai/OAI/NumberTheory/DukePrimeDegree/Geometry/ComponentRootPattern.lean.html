The measurable root pattern of actual ergodic components

A split diagonal rescales each real root group by a nonzero scalar. Thus it preserves the predicate that the whole root group fixes a measure, even when it moves that measure. For the normalizer-covariant component kernel this gives an invariant measurable event on the component base; it does not assert that individual components are fixed.
