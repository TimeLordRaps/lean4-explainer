Why an incident one-way root prevents the two-block argument

A nonzero root crossing the selected block moves its coordinate projection. If the stabilizer contains the entire root, it cannot preserve that block on any identity neighborhood. Thus a terminal strongly connected class cannot be substituted for a symmetric root block while incoming roots remain. This states the precise obstruction to that proposed reduction.
