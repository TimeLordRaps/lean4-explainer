    Finite backwards construction, indexed first by the number of remaining steps so that its recursion is structurally terminating.

    private def goodNumeratorAux
    (X : ℕ → ℝ) (I : ℕ → Finset ℕ) (res : ℕ → ℕ → ℕ → ℕ) :
    ℕ → ℕ → Finset ℕ
  | 0, j => Finset.Icc 1 ⌊X j⌋₊
  | n + 1, j => by
      classical
      exact (Finset.Icc 1 ⌊X j⌋₊).filter (fun u =>
        u ∈ goodNumeratorAux X I res n (j + 1) ∨
