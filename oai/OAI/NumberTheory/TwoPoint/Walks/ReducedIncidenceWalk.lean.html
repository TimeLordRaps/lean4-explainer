    Adjacent run labels differ, and consecutive transition points differ. The latter is exactly the nonzero run-increment condition.

    def IncidenceReduced (i : ι) : List (V × ι) → Prop
  | [] => True
  | (x, j) :: rest => i ≠ j ∧
      (∀ y k, rest.head? = some (y, k) → x ≠ y) ∧ IncidenceReduced j rest
