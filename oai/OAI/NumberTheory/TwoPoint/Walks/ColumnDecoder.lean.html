Decoding complete column patterns

Three binary streams merge regular segments with omitted runs, mark new runs, and mark imperfect positions. Representative indices supply omitted labels and imperfect attachments. All decoding is independent of numerical primes, quotient coordinates, and padding coefficients.

    Option CanonicalColumnLabel → List (Option CanonicalColumnLabel)
  | [], _, _ => []
  | (true, _) :: flags, runs, _ => none :: expandColumnRuns flags runs none
  | (false, true) :: flags, runs, _ =>
      runs.head? :: expandColumnRuns flags runs.tail runs.head?
  | (false, false) :: flags, runs, previous =>
