    The ordered inductive mean, with the harmless value vertex for an empty list. For a list of length j+1, append its last point with weight 1/(j+1).

    def inductiveMean (T : ConeData X) (h : CATZero X) : (n : ℕ) → (Fin n → X) → X
  | 0, _ => T.vertex
  | n + 1, v => CATZero.segment h
      (inductiveMean T h n (fun i => v i.castSucc)) (v (Fin.last n)) (1 / (n + 1 : ℝ))
