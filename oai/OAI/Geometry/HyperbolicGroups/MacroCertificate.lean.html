  11. def OAI.HyperbolicObstruction.MacroGraph.rank line 52

    Source documentation

    A leaf-elimination certificate, rooted at p. Ranks strictly rise towards the unique common line and the root; the exceptional rank subdivides its edge. This is a formula on the actual seven Fano vectors, not a graph hypothesis.

    def rank (p q : Fin 7) : Vertex → ℕ
  | .inl (.inl i) => if i = p then 8 else if i = q then 4 else 0
  | .inl (.inr l) => if p ≠ q ∧ Incident p l ∧ Incident q l then 6 else 2
  | .inr _ => if (3:Fin 7) = p ∨ (3:Fin 7) = q then
      if p ≠ q ∧ Incident p 4 ∧ Incident q 4 then if p = 3 then 7 else 5 else 3
    else 1
