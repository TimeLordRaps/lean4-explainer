  13. def OAI.ClosedSurfaceR4.JetPolynomial.lowJetCoordinateChange line 108

    Transport a positional low jet at T x to the positional low jet at x. The old positional components are unnecessary; the value and ordered jets are evaluated by the chain rule.

    def lowJetCoordinateChange (T : Base → Base) (p : Base × LowJet) : LowJet
  | .inl i => p.1 i
  | .inr (w,a) => ![p.2 (.inr (0,a)),
      coordinateChangeFirst T p.1 p.2 0 a,
      coordinateChangeFirst T p.1 p.2 1 a,
      coordinateChangeSecond T p.1 p.2 0 0 a,
      coordinateChangeSecond T p.1 p.2 0 1 a,
      coordinateChangeSecond T p.1 p.2 1 0 a,
