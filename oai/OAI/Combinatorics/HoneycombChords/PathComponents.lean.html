  7. def OAI.CriticalHoneycomb.Transfer.FiniteConfigurations.portRel line 154

    The hard-wall two-port graph: the two exterior markers have only their prescribed incident edge; internal adjacency remains unchanged.

    def portRel (R : α → α → Prop) (a b : α) : (α ⊕ Bool) → (α ⊕ Bool) → Prop
  | .inl x, .inl y => R x y
  | .inr false, .inl y | .inl y, .inr false => y=a
  | .inr true, .inl y | .inl y, .inr true => y=b
  | .inr _, .inr _ => False
