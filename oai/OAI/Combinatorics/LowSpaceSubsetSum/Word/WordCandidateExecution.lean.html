Materializing the actual words used by bounded rejection

The modulus is an already computed scalar argument. Each tail step reads one word, reduces it modulo that scalar, and pushes the result into the candidate array. The array is retained as part of the successful seed. The counter charges five scalar operations per step and the final return; the cell trace permits both the old and new array during a push.
