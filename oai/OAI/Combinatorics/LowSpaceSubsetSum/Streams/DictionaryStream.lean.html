A bounded dictionary driven by a stream cursor

The executable loop reads one key, updates the trie and its counters, and tail-calls with the next cursor. Lists and finite key sets below are proof views only; the loop stores neither a trace nor a set of all possible keys.

    Tail-recursive implementation. Every recursive call receives the updated cursor, trie and counters. A capacity violation stops immediately.

    def run {σ : Type u} (C : ℕ) (read : σ → Option (List Bool × σ)) :
    ℕ → σ → Tree → ℕ → ℕ → StreamResult σ
  | 0, s, t, processed, queries => ⟨s, t, false, processed, queries⟩
  | fuel + 1, s, t, processed, queries =>
    match read s with
    | none => ⟨s, t, false, processed, queries + 1⟩
    | some (key, next) =>
      if contains t key then run C read fuel next t (processed + 1) (queries + 1)
      else
