Cached tournament for merging row fronts

Each leaf holds at most one current occurrence of a row. Internal nodes cache the smaller child winner. Reading the winner is constant time; replacing one leaf recomputes just its root path. The candidate list below is an analysis view and is never stored in the tournament.

    Number of cached comparisons made by a leaf replacement.

    def replaceComparisons : {d : ℕ} → Tree α d → (Fin d → Bool) → ℕ
  | 0, .leaf _, _ => 0
  | _d + 1, .node _ l r, path =>
    1 + if path 0 then replaceComparisons r (fun i => path i.succ)
      else replaceComparisons l (fun i => path i.succ)
