Exact fixed-width keys for weights and top masks

Weights use a sign bit followed by 2u magnitude bits. Representation keys append the entire indexed mask, using one bit per input index. Every key has the same width, even on an outcome where its numerical value is not used. The input magnitude bounds guarantee injectivity for all actual weights.
