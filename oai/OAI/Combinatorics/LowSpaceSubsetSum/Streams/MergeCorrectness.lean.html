Complete and stopped tournament merges

The multiset view counts every row occurrence, even when all item fields coincide. Each successful advance removes exactly the reported occurrence. A sufficiently long trace therefore enumerates the whole product stream; the potential also bounds every stopped execution's number of advances.

    Analysis view of repeated advances. The program can stop between them.

    def trace (key : α → ℤ) (read : σ → Option (α × σ)) :
    ℕ → Tournament.Tree (Front d α σ) d → List α
  | 0, _ => []
  | k + 1, t => match advance key read t with
    | none => []
    | some (a, t') => a :: trace key read k t'
