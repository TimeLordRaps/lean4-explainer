Fixed-width binary dictionaries

An executable sparse binary trie for fixed-width keys, with exact membership and insertion semantics and a node-count bound. The array of retained records is separate; the trie is used to decide whether a key is new. This is the bounded dictionary component in the paper's stream implementation.

  | .empty, _ => True
  | .leaf, width => width = 0
  | .node _ _, 0 => False
  | .node zero one, width + 1 => HasWidth zero width ∧ HasWidth one width
