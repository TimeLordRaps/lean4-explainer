Replay with a budget checked before every iteration

charge is a bound for one read, one key, one callback and the loop's bookkeeping. A failed check returns before evaluating any of these operations. In the parent join this charge is polynomial in the input scale. The callback here is the bounded dictionary emitter, not another unbounded replay.
