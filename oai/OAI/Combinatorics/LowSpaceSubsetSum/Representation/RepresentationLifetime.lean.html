Simultaneous representation workspace

The prefix control stack contains no collectors. During a right task the left dictionary is retained; separator recursion uses filtered buffers only after that task completes. The conservative bound below may even count the task and checker workspaces simultaneously. Separator table storage is shared throughout the trial.
