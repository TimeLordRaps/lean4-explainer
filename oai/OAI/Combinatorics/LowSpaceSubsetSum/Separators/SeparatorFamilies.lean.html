Finite random separating families

For one fixed disjoint pair of masks, the separating subsets are counted exactly. A family is a uniformly chosen function from its index set to the set of eligible subsets: repeated sets retain distinct indices. Its point probabilities factor, so this is independent sampling with replacement, as required in the manuscript.
