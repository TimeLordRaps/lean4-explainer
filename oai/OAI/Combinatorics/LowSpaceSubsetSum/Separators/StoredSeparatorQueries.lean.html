Stored-mask codes and executed separator interval queries

A coordinate row is an explicit vector of ambient indices. Every mask bit is obtained by scanning the bounded stored index list. Its binary code then indexes an already prepared incidence table. Two measured binary searches answer the interval query without scanning that incidence list.
