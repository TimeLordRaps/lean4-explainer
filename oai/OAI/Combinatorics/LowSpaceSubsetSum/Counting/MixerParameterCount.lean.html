Exact integer mixer parameters from small stored half lists

The count streams all pair occurrences, removing adjacent equal sum keys with constant extra state. Neither the distinct-sum set nor the full mixer powerset is stored. The count therefore feeds the integer ordering and prime-width formulas without a real-valued oracle.
