Overflow probability for one fixed solution bucket

Equal actual weights are separated before prime collision estimates. A finite set of weight--mask keys may contain many keys with the same weight; linearity of expectation counts every such key when its weight differs from the fixed solution's weight. This is the bucket argument in both trial analyses.
