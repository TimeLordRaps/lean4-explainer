The fixed-profile encoding bound

Each actual coloring maps to the tuple of its changed row subsets and the original colors on them. Reconstruction proves this map injective. The row record permits arbitrary subsets of the fixed ambient sets, so overlap between those ambient sets can only enlarge the number of records.
