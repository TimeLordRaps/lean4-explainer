OAI/Combinatorics/Order/ChainToggle.lean

14 declarations, 0 contain sorry, 0 axioms

source

The alternating sum of finite chains cancels when an admissibility condition is stable under joining with a fixed nonbottom element. The involution inserts or removes the join of that element with the largest chain element that does not lie above it. Bottom is implicit, so an empty set represents the chain consisting of bottom alone and has sign +1.
