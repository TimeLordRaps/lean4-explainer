    Every same edge strictly decreases physical depth and never increases rank. Every earlier edge strictly decreases rank and never increases depth. No global count is part of this certificate.

    def Valid (a b : ℕ) : DependencyExpansion → Prop
  | .node d k m n same earlier =>
      m ≤ a ∧ n ≤ b ∧
      (∀ i, (same i).depth < d ∧ (same i).rank ≤ k ∧ Valid a b (same i)) ∧
      (∀ i, (earlier i).depth ≤ d ∧ (earlier i).rank < k ∧ Valid a b (earlier i))
