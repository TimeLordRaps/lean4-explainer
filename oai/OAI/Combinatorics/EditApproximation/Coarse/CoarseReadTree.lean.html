    A source descriptor is expanded by index arithmetic. No sliced or padded list is allocated. The function is the original stored input's read operation.

    def coarseReadTree (B : ℕ) {α : Type*} :
    (d : ℕ) → (ℕ → Option α) → CoarseSourceTree B α d
  | 0, read => .leaf (read 0)
  | d + 1, read => .branch (fun i =>
      coarseReadTree B d (fun j => read (i.val * B ^ d + j)))
