Expected active work in the concrete pruned coarse tree

The counter records the array units of the actual execution; pruning stops all descendant visits. Constant child overhead is charged to its expanded parent. The linear-sweep proof converts these units to rational operations; bit/RAM charging is separate.

  1. def OAI.EditApproximation.coarseExpectedArrayWork line 30

    Finite conditional expectation recurrence for the same active work. The root labels are independent uniforms, and each child uses its own independent recursive label tree.

    noncomputable def coarseExpectedArrayWork {B : ℕ} {α : Type u} (k : ℕ) (Q lam : ℚ) :
    {D : ℕ} → CoarseSourceTree B α D → ℚ → ℝ
  | _, tree, allowance =>
    if (tree.word.length : ℚ) ≤ allowance then 0 else
    match tree with
    | .leaf _ => (B * (2 * k + 1) : ℕ)
    | .branch children =>
      (B * (2 * k + 1) : ℕ) +
        ∑ i : Fin B, uniformMean (fun draw : Fin B =>
          coarseExpectedArrayWork k Q lam (children i)
            (lam * coarseChildThreshold B Q allowance draw))
