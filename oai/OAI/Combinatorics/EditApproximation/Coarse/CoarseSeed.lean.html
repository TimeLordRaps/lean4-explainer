The actual bounded-shift coarse tree

Section 3's deterministic shift representation uses a complete finite branching tree with empty/singleton source leaves. Bounded integer shifts are encoded by Fin (2k+1); code k is shift zero. Virtual target positions are represented by fresh none symbols in a finite surrounding frame.
