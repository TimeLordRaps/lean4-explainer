A cumulative allocation counter for the actual memo execution. It keeps all local allocations until the entire run finishes, so it also bounds peak space. A read retains three continuation/result cells. Each memo call reserves its address workspace, key bits, traversal frames and the possible new trie path; existing values and input words are shared by reference.
