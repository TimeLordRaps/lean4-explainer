An explicit coordinate-list proposal for the companion chain

Only ordered coordinates are enumerated. The arithmetic binary-profile program generates the possible exchanges, after which the actual chain state predicate removes disallowed states. A dyadic list index has exactly the same proposal law as the abstract injection.
