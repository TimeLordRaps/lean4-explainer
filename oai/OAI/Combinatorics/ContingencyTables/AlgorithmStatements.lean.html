Main algorithm statements for result 200

The samplers and counter use a finite transition table, independent fair bits, binary inputs and explicit bit-operation runtime bounds. No counting or sampling oracle is part of the machine. The exact sampler's expected runtime uses a summable tail series, avoiding the default value of an undefined infinite sum.
