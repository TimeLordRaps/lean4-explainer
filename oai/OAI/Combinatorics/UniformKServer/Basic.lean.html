A concrete bit-machine model for the main conclusion. There is a fixed finite number of work tapes and finite control states, independent of the instance. The input tape is read-only. One transition reads one fresh unbiased bit and can output at most one bit. Halting/yielding stutters, allowing exact finite uniform averages without rejection sampling. A request installs only its own binary input word; it does not reveal either the horizon or the clock.
