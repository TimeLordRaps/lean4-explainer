Rational paths from a closest return

The representatives are real vectors with explicitly integral errors along an arithmetic progression. The minimal return to a half-open rectangular box forces the integral numerator of the return to be primitive. The proof uses the actual intermediate sample and uniqueness in a fundamental interval.
