Drift relative to actual heavy adaptive intervals

The heavy multiplicity is counted over Fin k using the actual literal full label. Its natural-index fiber has the same cardinality. Equal labels place the actual centered representatives in the same half-open interval, providing the width bound required by the general endpoint argument.
