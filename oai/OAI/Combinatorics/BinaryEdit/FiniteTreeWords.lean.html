Recursive row words for the finite tree

The recursion in equation (finite-word) uses an additive state group, node shifts and leaf symbols. It is instantiated with the product of cyclic groups in the manuscript.

  1. def OAI.TreeEdit.BinaryLower.FiniteTree.nodeWord line 20

    A row is the ordered concatenation of the m child words. At a leaf the word consists of its single tagged state symbol.

    def nodeWord {m : ℕ} (T : ℕ) (leaf : List (Fin m) → A → Γ)
    (u : List (Fin m) → A) : ℕ → List (Fin m) → A → List Γ
  | 0, p, x => [leaf p x]
  | h + 1, p, x => (List.range T).flatMap fun a =>
      (List.finRange m).flatMap fun i => nodeWord T leaf u h (p ++ [i]) (x + a • u p)

/-- All node words at a given height have exactly the manuscript's length. -/
