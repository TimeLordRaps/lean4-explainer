Uniform bounded height in a fixed metric and an arbitrary norm

The auxiliary Riemannian metric is used only to construct smoothing. The identity comparison transfers every uniformly controlled family from the specified proper chain metric. A bounded linear change of coordinates then returns the estimate to the specified norm on the canonical height space.

    The standalone uniform bounded-height theorem. In particular the fixed metric can be any left-invariant proper Riemannian metric. The finite group is chosen before the quasi-isometry constants, and the bound is uniform over all self quasi-isometries with those constants.
