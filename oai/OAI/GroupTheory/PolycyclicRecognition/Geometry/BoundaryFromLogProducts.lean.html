Boundary limits from contracting logarithmic increments

The actual finite BCH estimate constructs uniform normalized limits in a common compact set. Continuous trajectories then define a continuous boundary map on an actual quotient whenever trajectories in a common fiber are asymptotic. Only that geometric fiber condition remains an input here; no boundary map or compact shadow is assumed.
