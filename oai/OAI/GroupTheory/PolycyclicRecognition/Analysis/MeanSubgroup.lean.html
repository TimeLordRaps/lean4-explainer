Restricting invariant means to subgroups

The finite-index height kernel in the recognition argument inherits amenability from the ambient group. The construction below works for an arbitrary subgroup: choose representatives for right cosets, construct an equivariant map to the subgroup, and extend each bounded function by composition with this map.
