Stationary sampling along controlled paths

A fixed finite mesh selects one normalized pair good for most independently sampled endpoints. The coarse metric bound extends that mesh estimate to the whole image path and retains the logarithmic error explicitly.

  1. theorem OAI.PolycyclicRecognition.eventually_exists_pair_good_on_paths line 31

    The finite-mesh bad set has mass less than one half; outside it every point of the image path has controlled height. No supremum-in-L² is used.
