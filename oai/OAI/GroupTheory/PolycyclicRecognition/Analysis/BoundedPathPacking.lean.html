From polynomial-volume thickenings to bounded-height path packing

The endpoint set need not be measurable. We pack finite separated subsets using Haar mass and then take a maximal one. Only the enclosing coordinate regions are measured; this is the precise bridge needed from the Lie-coordinate bounds.
