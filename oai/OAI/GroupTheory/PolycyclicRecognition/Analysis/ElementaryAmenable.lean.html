Elementary amenability of the height extension

We use the closure definition: finite and abelian groups, subgroups, quotients, extensions, and directed unions. For the last operation it suffices to use the directed union of the finitely generated subgroups. This formulation is exactly what is needed when the corrected height kernel is locally virtually nilpotent. In particular, no finite generation of that kernel is imposed.
