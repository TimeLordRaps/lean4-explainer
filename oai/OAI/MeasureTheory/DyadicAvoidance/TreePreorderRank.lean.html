    Preorder rank of a path. On paths of length at most d, this is the usual zero-based root-first rank in the complete tree.

    def rank {K : ℕ} : ℕ → List (Fin K) → ℕ
  | 0, _ => 0
  | _ + 1, [] => 0
  | d + 1, i :: p => 1 + i.val * size K d + rank d p
