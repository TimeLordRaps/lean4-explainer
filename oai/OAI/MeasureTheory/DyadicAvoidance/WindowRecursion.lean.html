    Total span occupied by the windows in a complete tree of the given height. At a bottom-level child there is no following subtree gap; at higher levels the incoming window is followed by one gap and the complete child subtree.

    def span (M g r₀ : ℕ) : ℕ → ℕ
  | 0 => 0
  | h + 1 =>
      M * (max r₀ (g + span M g r₀ h) +
        if h = 0 then 0 else g + span M g r₀ h) + (M - 1) * g
