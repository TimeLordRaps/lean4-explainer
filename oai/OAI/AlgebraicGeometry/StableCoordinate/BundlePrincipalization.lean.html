Explicit global principalization in the quadric bundle

This module gives polynomial identities, valid in every commutative ring, for the principalization in source Section 4, Lemma bun:principalization. Unlike the source proof, the argument uses an explicit global Bezout identity and requires neither localization nor prime-spectrum gluing.
