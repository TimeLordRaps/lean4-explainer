Separation for the integer filtration

The variables are ordered (p,s,u,F,J). The integer weight is -exp(p) + exp(F) + exp(J). This file proves the negative-weight power-divisibility estimate, and separates every image filtration in a Noetherian domain whenever the image of p is a nonunit.
