Elementary certificates for the graded hypersurface

The negative-coordinate proof uses localization away from p. This file establishes that p is regular in the actual graded hypersurface quotient, using the exact relation rather than a domain assumption. It also supplies localization-domain descent and nonvanishing certificates for the five specified homogeneous generators.
