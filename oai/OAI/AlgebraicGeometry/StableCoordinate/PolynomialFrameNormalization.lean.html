Ordinary-polynomial adapters for normalized determinant lifts

The additive-coaction interface uses ordinary and iterated Polynomial, while multivariate frames are convenient for the underlying unit rigidity argument. These adapters give the same normalization and uniqueness directly for the coaction parameter type, without changing variables through an equivalence.
