source

Finite table machines for the result. X is the public input alphabet (all uses for machines as space bounds have finite types); J indexes a fixed number of other read-only tapes, on a binary alphabet. Each read-only tape is endmarked and has one confined head. Work tapes for the simulator and accessor are two-way, with unit moves. Terminal output in a finite set may be specified in the transition table (equivalently transition to the associated halt state). TM transitions with writes write before moving.

Space convention is visited work cells (including the origin of each work tape), weighted by bits/symbol in the fixed alphabets, excluding read-only tapes. Since visited sets are intervals, we use a window certificate including all head positions during the run.
