Bounded first-address tables for actual powering constraints

For a graph with numbered vertices and ports, each stored local-opinion index is the first address in allAddresses that reaches the requested vertex. The search traverses bounded port words, never the ambient vertex set.

The walk table stores one base dart and two address indices per traversed edge. Looking up the endpoint labels at those indices gives exactly the existing finitePortSelector decoders, including when addresses collide. The resulting finite table predicate equals the actual powering predicate.
