Actual graph data consumed by the powered-row machine

The data fields are computed from the stored rotor and base relations. The endpoint masks compare actual bounded word endpoints, in allAddresses order. Their first true positions equal the already checked canonical address indices.

Reversing a row swaps the two masks and transposes each base predicate. Thus one fixed row machine handles both directions. Its label lookup depends only on the fixed degree and radius. The final identities describe the exact unary input fields and the exact serialized relation emitted for a stored output row.

These are semantic producer-to-emitter identities. A machine implementation that computes the input data from the serialized rotor is a separate frontend.
