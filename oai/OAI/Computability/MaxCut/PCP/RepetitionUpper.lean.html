    Source documentation

    Expectation of f evaluated at the number of successes in n independent Bernoulli trials. The recursion itself specifies the product distribution.

    def bernoulliAverage (p : Rat) : Nat → (Nat → Rat) → Rat
  | 0, f => f 0
  | n + 1, f =>
      (1 - p) * bernoulliAverage p n f +
        p * bernoulliAverage p n (fun k => f (k + 1))
