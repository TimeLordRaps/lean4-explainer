Exact affine-table keys for the v2 outer questions

The retained data has one entry at every original block position. A full entry contains the equation occurrence ID, a singleton entry contains the actual variable ID, and the first component is the entire reduced affine intercept. The common coefficient-normalization implementation below is independent of every latent-gadget existence or inverse theorem.

The explicit binary slope cases justify its use for the v2 rank-zero, rank-one, and rank-two rule. In particular, the third-position pullback adds the parity intercept twice, so exact sharing preserves the intercept as well as the slopes.
