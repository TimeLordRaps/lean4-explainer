An explicit name compaction for finite three-literal CNF formulas. Only the occurring names are scanned: the declared variable count is never enumerated. Both assignment transports preserve every clause evaluation and therefore every finite clause-score gap. The encoding bound is a size theorem; a machine running-time bound and the constant-gap PCP construction remain separate.
