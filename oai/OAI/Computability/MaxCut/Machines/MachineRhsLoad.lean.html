Execute all fixed outcome rows after the existing RHS loader. A single dispatcher freezes the loaded finite RHS vector into labels. Every row is an actual address-edge phase; no row-run or whole-loop execution is assumed. Program definitions contain only fixed templates, literal permutations, and tape/label placement. Numeric names, radix, and capacity occur only in tapes and the semantic correctness hypotheses.
