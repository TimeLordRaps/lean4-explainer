Actual dummy-owner body of regularization

The owner is a physically stored unary index. The code computes its cloud metadata, initializes local index and fuel, skips the family computation when padding is zero, and otherwise generates one rotor for all dummy vertices of this owner. Each vertex iteration consumes one fuel bit and increments both physical vertex indices. The final checked addition and cleanup leave only the updated global index, prefix, and accumulated output.
