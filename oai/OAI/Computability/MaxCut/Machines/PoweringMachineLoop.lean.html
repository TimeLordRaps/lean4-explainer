source

Actual finite-control preparation and enumeration for the powered-table machine. The degree and radius determine a fixed multiplier B = 2*d^t. Only the input vertex count varies at runtime, and it is stored on unary tapes. The header machine consumes a cloned first input field, preserving its unread suffix, and writes the three fields needed by the outer loop.

The row enumeration lemmas specify the canonical suffix invariant used with MachineCountedLoop. They do not stand in for the caller's per-row machine traces, which must be supplied by the actual walk and relation evaluator.
