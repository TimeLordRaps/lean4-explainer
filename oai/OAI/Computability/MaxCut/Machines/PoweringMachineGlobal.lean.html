The fixed global powering machine

For fixed degree d and radius parameter n, this is one concrete finite machine: initialization, unary vertex guard, the fixed vertex-row producer, and output-header/cleanup instructions are connected by explicit labels. Its definition takes no input graph, vertex count, or program callback.

The code equations below expose each actual branch for the separate runtime proof. The variable-size input graph and counters reside on physical tapes.
