Exact coordinate-order bridge from the checked tuple odometer to the outer reduction's occurrence enumeration. The odometer changes coordinate zero fastest; ActualEnumeration.functions changes it slowest. Reading saved digit j.rev as query coordinate j matches the complete ordered list. No primitive machine or assumed whole-loop runtime is introduced here.
