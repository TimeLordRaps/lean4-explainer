Realizing the existing Håstad noise law with a finite uniform tape

A tape contains one element of Fin D per coordinate. The corresponding noise bit is true exactly when that element has value zero. For D > 0, its law is exactly Foundations.Hastad.noiseWeight ((D : ℝ)⁻¹).

The construction also permits an empty coordinate type and D = 1.
