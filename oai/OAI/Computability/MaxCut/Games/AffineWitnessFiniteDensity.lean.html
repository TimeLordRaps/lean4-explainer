Finite indicator expectations as conditional cardinality ratios

These identities use the complete finite sample set in the denominator. They also cover the empty set, for which both the expectation and the ratio are zero. The equivalence variant transfers both the event and the sample space, so no conditioning factor is lost when changing representations of a slice.
