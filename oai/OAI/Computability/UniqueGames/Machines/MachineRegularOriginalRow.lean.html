Machine execution for an inherited regularization row

The machine reads the original reverse index from the physically stored input table. The unread working copy then starts at the 4096 original predicate fields; a fixed finite Boolean block copy retains exactly those fields. Unary arithmetic computes the new reverse index, and the checked row emitter appends the three physical fields. No input table or unbounded arithmetic function is stored in the machine's finite state or instructions.
