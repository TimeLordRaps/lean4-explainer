Materializing a cloud rotor inside the regularization machine

Core tape 4 contains the unary cloud size and core tape 7 receives the complete forward rotor table. The actual family computation runs on private tapes; three retained unary words are then physically drained. All other core tapes are preserved and all private tapes are empty on return.
