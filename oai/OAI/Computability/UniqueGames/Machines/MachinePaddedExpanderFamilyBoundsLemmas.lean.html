Actual requested-size to expander-table computation

One finite program physically computes the padding level and then constructs the complete corresponding rotation table. The level output of the first phase is the input tape of the second phase. The actual execution preserves the request, retains the padded size, and has a fixed polynomial time bound in the unary request length.
