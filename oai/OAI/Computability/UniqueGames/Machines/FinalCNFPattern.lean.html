Concrete relation addresses for the final Boolean verifier

Six-bit labels use the already checked executable little-endian enumeration. A twelve-bit CNF pattern is split into its two endpoint labels, then addressed in the graph table's row-major order. This fixed address map uses the actual VerifierToCNF.patternAt enumeration, so no assumed correspondence between two enumeration orders is needed. The graph interpretation is an explicit relabeling of the validated table semantics.
