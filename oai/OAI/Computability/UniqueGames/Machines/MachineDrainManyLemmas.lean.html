Actual cleanup of a finite list of work tapes

Each list position supplies one fixed drain label. The finite-sequence theorem composes the checked physical drains; neither the list nor a runtime tape index is stored in the register. Repeated tape names are allowed. The cleanup bound uses the lengths before cleanup, since draining can only shorten a tape.
