Physical postprocessing of the two-side address codec. The program reads 2*C,q,m, writes C,q,m, and replaces each row u,C+v,table by u,v,table. Only the fixed alphabet size q occurs in finite control. All input-dependent integers reside on unary tapes. Six Bool tapes suffice.
