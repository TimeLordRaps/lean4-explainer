Concrete data and tape frames for an actual expander-row computation

Only the five actual row inputs are stored. Every address, table return and finite control value below is computed from those inputs. The thirteen tape frames use the existing phase-output functions. These are data identities and size bounds, not assumed machine executions. Kernel-checked with Lean 4.33.1.
