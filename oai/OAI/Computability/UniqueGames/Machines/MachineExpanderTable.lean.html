Complete finite machine execution for the next expander table

The initialized old table and unary vertex count are consumed by one actual finite program. The machine writes precisely the complete square/zigzag rotation table, preserving its old table and all promised framing. The bound is quadratic in the unary old-table length for each fixed small graph.
