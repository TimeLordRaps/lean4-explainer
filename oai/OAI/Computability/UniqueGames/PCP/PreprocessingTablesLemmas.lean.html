Concrete preprocessing table algorithm

Given one fixed expander base table, this function computes regularized cloud rows, pads the whole vertex set, overlays a stored family table, and adds the half-lazy rows. It is total even on zero-dart input tables. The bounds below concern actual output data; an actual TM2 execution certificate is a separate theorem and is not inferred from these size bounds.
