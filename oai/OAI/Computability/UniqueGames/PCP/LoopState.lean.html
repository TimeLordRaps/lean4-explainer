source

Exact tape invariant for the old-dart loop. The cursor stores the remaining input rows, while the reversed tape stores precisely the output headers and the blocks already emitted. The scan and index-scan tapes are unconstrained: the next lookup prefixes fresh copies and retains old residues as suffixes. Finite control state is specified by the actual execution theorems using this tape invariant.
