Executable directed graph tables over a fixed finite alphabet

The alphabet size q is fixed by the encoding, not encoded as a variable input field. The header stores vertex and directed-dart counts. Each ordered dart row stores its tail, reverse index, and every q*q predicate bit in order b+q*a. All fields use the existing unary natural-word codec. Decoding validates graph laws and preserves loops and repeated darts. Size bounds count the complete serialized table and make no running-time assertion.
