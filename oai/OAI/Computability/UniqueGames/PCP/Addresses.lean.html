Affine numeric fields of the alphabet-reduction table

The five unbounded unary inputs are n, m, e, tail, head, in that order. Every field uses a fixed list of natural coefficients and one bounded offset. For a fixed local event and slot, the query field's coefficient list does not depend on the input predicate. The predicate changes only its bounded offset. Evaluation uses the same Emitter.affineValue as the actual unary emitter.
