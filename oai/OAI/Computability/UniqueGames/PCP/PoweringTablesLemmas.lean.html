Executable tables of the actual powering graph

The input rotor and every base predicate are stored finite vectors. The output has one row for each start vertex, bounded port word, and orientation, with the two orientations adjacent. Every complete predicate table is generated from the bounded first-address lookup test. Degree and walk length fix the output alphabet; neither the alphabet nor an address list depends on the input vertex count.
