Vertex-major serialization of the actual powering table

Each vertex contributes a fixed number of consecutive stored dart rows. The identities below group the actual vector, including every predicate entry, and then apply the shared word codec. They do not assume an output layout or assert a machine running time. Unary bit lengths can vary with the stored indices.
