A certified machine for fixed symbol substitution

For a fixed table emit : Bool → List Bool, this actual finite TM2 machine produces (input.flatMap emit).reverse in exactly 2 * input.length + 1 transitions. It has one input-pop transition and one literal-emission transition per input symbol, followed by the final empty pop. Literal emission is a fixed finite statement; its maximum number of pushes depends only on emit.

This is a machine primitive, not a runtime theorem for the Unique Games reduction.
