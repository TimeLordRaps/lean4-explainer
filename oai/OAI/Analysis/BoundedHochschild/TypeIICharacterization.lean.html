Type II structure without an assumed trace

A nonzero abelian projection has a central type I support, with the type I condition tested on all subprojections. Thus absence of a type I central part is equivalent to absence of abelian corners, before constructing a trace. The projection-halving theorem can consequently use exactly the type II hypothesis of the main application.
