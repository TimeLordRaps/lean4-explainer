Matrix averages in the centralizer of a vector state

Finite signed-permutation averages preserve a vector state centralizing the matrix stages. Their bounded weak cluster points are scalar by relative irreducibility. State preservation identifies each scalar, and the ultrafilter criterion then gives actual weak convergence of the whole sequence. No traciality of the ambient algebra is required.
