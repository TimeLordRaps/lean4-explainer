Bounded field multiplication and constant translation-fixed fields

Bounded measurable operator fields act on the actual vector-valued L² space. Finite-measure indicator tests recover their coefficients, so this action is faithful modulo almost-everywhere equality. A decomposable operator commuting with every real translation is a constant operator. No decomposability assertion for an arbitrary operator is assumed here.
