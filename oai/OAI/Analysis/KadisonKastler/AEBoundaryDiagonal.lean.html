Diagonal comparison from almost-everywhere cocycle data

A countable group has a common invariant conull set for the cocycle laws and approximation bounds. Outside that set the generating family is filled with one good value. This provides global bounds for the least-vector and polar constructions; covariance is required only on the conull set.
