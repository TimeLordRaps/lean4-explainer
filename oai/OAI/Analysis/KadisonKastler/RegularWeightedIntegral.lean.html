Integrable scalar weights on bounded operator fields

Vectorwise integration needs only strong measurability on each vector. An integrable scalar weight therefore defines a bounded operator, and commutation and von Neumann algebra membership pass to this operator. This applies in particular to the compactly weighted convolution operators in the regular representation.
