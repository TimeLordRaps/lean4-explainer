The actual diagonal partition in a matrix amplification

Outer row indices and inner matrix-unit indices give n*k mutually orthogonal diagonal projections. Relabeling by finProdFinEquiv matches the phase multiset supports with the concrete support projections used in the clipped-column estimate.
