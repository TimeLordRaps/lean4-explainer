Actual coefficients of the finite phase words

The coefficients are indexed by label multisets, so words with the same phase monomial are grouped before applying Parseval. Their supports are the sums of precisely the projections whose labels occur in the multiset.

    The degree-zero convention allows the positive coefficients to be defined by removing a first label.

    def positivePhaseCoefficient (e : ι → A) (v : A) : (r : ℕ) → Sym ι r → A
  | 0, _ => 1
  | r + 1, s => ∑ a : {a : ι // a ∈ s},
      e a.1 * (if r = 0 then 1 else v) * positivePhaseCoefficient e v r (s.erase a.1 a.2)
