Translation-invariant measurable fields are constant

For each translation the exceptional null set may differ. Fubini and the measure-preserving shear (s,t) ↦ (s-t,t) nevertheless give a single almost-everywhere constant representative. The operator-valued version uses only countably many dense Hilbert coefficients.
