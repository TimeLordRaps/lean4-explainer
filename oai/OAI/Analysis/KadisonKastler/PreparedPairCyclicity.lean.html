Cyclicity from the common left and right vector actions

The projection onto the closed commutant orbit belongs to the original von Neumann algebra. Common vector actions make it commute with the irreducible common subalgebra, so its scalar value is one. Applying the same argument to the commutant proves both cyclicity and separation. No cyclicity or standard-form conclusion is assumed.
