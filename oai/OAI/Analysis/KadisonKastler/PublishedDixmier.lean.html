The published Dixmier averaging input

Only the contraction case is retained. Blackadar, Operator Algebras, Definition III.2.5.16 and Theorem III.2.5.18, p. 282 (PDF p. 290), state that the norm-closed convex hull of the unitary conjugates of an element of a von Neumann algebra meets its center. This input contains no comparison between different algebras and no perturbation bound.
