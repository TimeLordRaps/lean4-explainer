One vector satisfying every branch halfspace

The finite-prefix witnesses lie in the same actual weakly compact set. Continuous linear evaluations define weakly closed halfspaces. Compactness then keeps one vector in all the constraints. In the final application the set is the whole unit ball of the closed difference span, viewed in X.
