Actual norm and weak carriers for the fixed point argument

The public reflexivity predicate uses the continuous bidual. All maps on convex sets use their norm subtypes. Weak convergence takes place on a separate subtype of WeakSpace, so it cannot alter the given norm. The data structures record conclusions of the reduction from actual fixed-point-free counterexamples.
