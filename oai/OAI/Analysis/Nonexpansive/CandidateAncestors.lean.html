The stored ancestor lists are the actual paths of the constructed tree

The stage recursion appends the current parent's map to its stored strict ancestor list. This is exactly the recursion defining pathDisplacement. The finite sums used when selecting candidates therefore bound the final tree's actual proper-ancestor displacement.
