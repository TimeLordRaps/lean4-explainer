Actual root states during right-to-left switching

At cutoff t, the leaves with index strictly below t retain their labels; all other leaves have the common terminal value. Decreasing t by one is one actual switch. Every increment below is a difference of these evaluated root states, so finite telescoping never assumes that a node map is linear.
