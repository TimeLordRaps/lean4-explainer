A common terminal index for finitely many detectors

This finite-filter argument chooses one actual index at which all scalar prediction detectors and the total displacement bound hold. Its applications supply the scalar limits by evaluating continuous linear functionals on the actual weak prediction limits, and supply displacement convergence for the actual finite collection of node maps.
