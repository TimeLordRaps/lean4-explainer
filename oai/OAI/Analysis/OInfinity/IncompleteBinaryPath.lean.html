Uniform paths for the actual incomplete binary cocycle

Binary fragmentation needs two orthogonal isometries, not a coisometric row. For the complemented binary corner map, the splitting defect of an iterated cocycle has a path controlled by the original one-step unitary. Thus the bound is independent of the number of cocycle factors. The binary family need not generate a dense subalgebra of O∞.
