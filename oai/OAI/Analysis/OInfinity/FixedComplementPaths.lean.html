Constant-complement paths for the concrete common-corner comparison

The path of the relative binary comparison stays in its actual corner. Combining it with fixed-support shrink paths gives a unitary path with the prescribed complementary isometry at every time. Its initial value is displayed literally; no connectedness of that initial value is assumed.
