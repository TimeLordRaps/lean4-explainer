The finite block flip and the actual row cocycle

The block flip permutes the composed row and is a selfadjoint relative unitary. For commuting rows, multiplying the actual row cocycle by this flip moves that cocycle into the shifted corner. The shifted cocycle is retained: the identity does not make the cocycle finite-order.
