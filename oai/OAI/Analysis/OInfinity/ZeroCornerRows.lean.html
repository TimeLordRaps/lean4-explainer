Finite Cuntz rows in the explicit complementary corner

Repeatedly splitting the first range of a relative Cuntz pair produces every finite row size. All ranges still sum to the same projection q; the complement 1 - q is retained. The commutator estimate grows only linearly with the number of splittings.

    At stage zero the row is the corner unit. Every successor replaces it by b followed by the old row multiplied on the left by a.

    def zeroCornerRow (q a b : E) : (n : ℕ) → Fin (n + 1) → E
  | 0, _ => q
  | n + 1, i => Fin.cases b (fun j => a * zeroCornerRow q a b n j) i
