Transferring almost-everywhere compatibility to actual grid choices

Independent shifts for distinct labels have the required finite product law. Each shifted grid level has a law absolutely continuous with respect to Haar measure on the circle. Consequently every completed-product null failure set remains null for actual grid tuples. Repeated levels of one label are not treated as independent; the tuple map explicitly requires distinct labels.
