Selecting an actual reciprocal-integer grid

The grid spacing must be 1/N so that the staircases respect period one. The laws of the uniform shifts change with the spacing. This selection uses those actual product laws, keeps any prescribed conull compatibility event, and makes both the wedge cost and scaled terminal count small.
