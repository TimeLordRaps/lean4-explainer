Actual masked circle cost away from the retained core

Mask boundaries lie inside the core. On its complement every active mask is locally present, so the circle cutoff formula holds there. This identifies the masked random cost with the actual spatial wedge sum and proves integrability from each coordinate's own masked L² norm.
