Actual contraction labels obstruct short walks

One label is chosen for each edge of a hypothetical short walk. These labels are padded to the full degree using one fixed member of the same set of directions. Symmetry moves each edge's direction to the contracted slot, so evaluation on this single tuple is constant along the walk. This contradicts robust nonvanishing of the difference of its endpoints.
