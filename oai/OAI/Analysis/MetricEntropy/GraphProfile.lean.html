The actual logarithmic graph matrix

Columns retain both their vertex and their admissible partition set. The graph metric takes values in ENat, so disconnected vertices have profile zero. The row separation proof uses an actual coordinate of this matrix; the finite field construction supplies its graph-separation hypothesis separately.
