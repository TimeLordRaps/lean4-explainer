A bounded greedy family of pivots

At each step, choose a set whose mass outside the current union exceeds the threshold if such a set exists. Otherwise choose a fixed padding center. Padding still enlarges the union, so it cannot increase any residual mass. If the residual bound failed after s steps, all preceding steps would have made a strict gain greater than the threshold, contradicting total mass at most one and 1 ≤ s * θ.
