The matrix subfactor is the entrywise image of the original inclusion. Projection comparison transports the scalar bound to all sufficiently small matrix corners. Popa's local conjugacy input chooses the free copy, while all native GNS geometry is the canonical generated geometry. The remaining local input consists exactly of the published structural data for that geometry; it contains no commutator bound.
