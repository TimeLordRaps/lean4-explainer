Centered symmetry tests for contractions. The selfadjoint two-by-two dilation has opposite diagonal entries, so its normalized trace vanishes for every linear functional. Applying it to the selfadjoint off-diagonal matrix of an arbitrary contraction yields a four-by-four symmetry with the original contraction as one entry. This avoids any extra spectral trace-equality hypothesis.
