Irreducibility of an entrywise matrix inclusion

The scalar matrix units force any relative commutant element to be a constant diagonal matrix. Its diagonal entry commutes with the original inclusion, so scalarity of the original relative commutant proves scalarity after matrix amplification. No normality or factor classification is used.
