  23. def OAI.PartitionConsistency.ForcingQuotient.AtomicData.Force line 163

    Source documentation

    Formula-by-formula forcing: existential forcing is local density, NOT a maximum principle or selection of a single global witness name.

    def Force (A : AtomicData P N) {n} (v : Fin n → N) (p : P) : BasicFormula n → Prop
  | .bot => False
  | .mem x y => A.MemF p (v x) (v y)
  | .equal x y => A.EqF p (v x) (v y)
  | .conj φ ψ => A.Force v p φ ∧ A.Force v p ψ
  | .neg φ => ∀ q, q ≤ p → ¬ A.Force v q φ
  | .ex φ => ∀ q, q ≤ p → ∃ r, r ≤ q ∧ ∃ x : N, A.Force (Fin.snoc v x) r φ

  35. def OAI.PartitionConsistency.Formula.toBasic line 315

    Source documentation

    Translation to the finite Boolean/existential basis used in the quotient truth proof. This changes no set-theoretic predicate or quantifier domain.

    def toBasic {n} : Formula n → BasicFormula n
  | .bot => .bot
  | .mem x y => .mem x y
  | .equal x y => .equal x y
  | .imp φ ψ => .neg (.conj (toBasic φ) (.neg (toBasic ψ)))
  | .conj φ ψ => .conj (toBasic φ) (toBasic ψ)
  | .disj φ ψ => .neg (.conj (.neg (toBasic φ)) (.neg (toBasic ψ)))
  | .all φ => .neg (.ex (.neg (toBasic φ)))
  | .ex φ => .ex (toBasic φ)

/-- Classical truth is invariant under the translation to the basis. -/

    Mentions: OAI.PartitionConsistency.Formula, OAI.PartitionConsistency.Formula.neg
