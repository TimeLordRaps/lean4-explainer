    Iterated positive Pieri, with an explicit coloring of the added strips. The map is surjective and equivariant for all permutations preserving each strip, not just for the smaller symmetric group.
    theorem stripChain_restriction {bs ν μ} (hs : SizedStripChain bs ν μ) :
    ∃ (c : Fin μ.card → ℕ) (F : Specht (shapeTableau μ) →ₗ[ℂ] Specht (shapeTableau ν)),
      Function.Surjective F ∧
      (∀ i, c i ≤ bs.length) ∧
      (∀ i, c i = 0 ↔ i ∈ Set.range (tableauInclusion (shapeTableau ν) (shapeTableau μ) hs.le)) ∧
