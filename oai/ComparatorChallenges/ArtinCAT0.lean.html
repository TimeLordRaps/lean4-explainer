  14. theorem OAI.ArtinCAT0.main Challenge statement: An explicit Artin group with no geometric $\mathrm{CAT}(0)$ action sorry line 65

    L4DEL explanation

    We construct an Artin group on 116 generators that admits no proper, cocompact isometric action on a nonempty proper CAT(0) space.

    — OpenAI Artin-CAT(0) manuscript (abstract)

    One question which is still open for both spherical and non-spherical Artin groups is whether they are CAT(0) groups

    — Ruth Charney, An introduction to right-angled Artin groups (2007)

    An explicitly presented Artin group on 116 generators cannot act geometrically on any nonempty proper $\mathrm{CAT}(0)$ metric space, in any dimension.

    1. explicitMatrix is proved symmetric, has diagonal entries one, and has every off-diagonal label in $\{2,3,\infty\}$. Finite labels impose alternating Artin relations; the label $\infty$ imposes no relation.
    2. GeometricAction combines four requirements: the metric space satisfies the stated $\mathrm{CAT}(0)$ triangle inequality, every group element acts isometrically, the action is proper, and one compact set has translates covering the space.
    3. The final conjunct quantifies over every metric space, proper-space structure, nonempty witness, and action of this exact Artin group. It therefore refutes the group-level CAT(0) conjecture, not merely one proposed metric on one standard complex.
    4. Ruth Charney's survey recorded the proper-cocompact-isometric-action question as open for spherical and non-spherical Artin groups. The Lean target gives one explicit counterexample rather than classifying all Artin groups.
    5. Trust boundary: this comparator declaration ends in by sorry. The pinned comparator configuration pairs it with OAI.GroupTheory.ArtinCAT0.Main; the site's Lean trust result, not this annotation, determines whether that separate solution module checks.
