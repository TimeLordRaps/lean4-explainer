  5. def OAI.UniqueGamesTheorem.Foundations.Target.countSatisfied Count satisfied constraint occurrences line 31

    L4DEL explanation

    Its value is the fraction of satisfied constraints

    — OpenAI, The Unique Games Theorem (2026), p. 2

    countSatisfied labeling constraints recursively counts how many entries in the constraint list evaluate to true under one labeling.

    1. The empty list contributes zero.
    2. For a head constraint, add one when constraint.satisfied labeling is true and zero otherwise, then recurse on the tail.
    3. This is an occurrence count: repeated equal constraints are counted repeatedly. The later game value divides this natural number by the nonempty list length.

    Sources and attribution: Pinned Lean source (fd4aeeb2ee4f), Pinned OpenAI Lean source for Unique Games, OpenAI, The Unique Games Theorem (2026), p. 2

    Also declared: OAI/Computability/UniqueGames/Model.lean:31 (same declaration text).

    def countSatisfied {n q : Nat} (labeling : Fin n → Fin q) :
    List (Constraint n q) → Nat
  | [] => 0
  | constraint :: rest =>
      (if constraint.satisfied labeling then 1 else 0) + countSatisfied labeling rest

  | 0, _ => none
  | _ + 1, false :: rest => some ([], rest)
  | fuel + 1, true :: input => do
      let (clause, input) ← parseClause input
      let (clauses, rest) ← parseClauses fuel input

  | _ + 1, [] => none
