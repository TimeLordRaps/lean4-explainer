  31. theorem Cantor Cantor: no function from α to its power set is surjective line 237 source

    L4DEL explanation

    Build the set of elements not in their own image; it cannot be anyone's image.

    1. intro f surjf assumes f : α → Set α is surjective, and the goal becomes a contradiction.
    2. let S := { i | i ∉ f i } defines the diagonal set, and rcases surjf S gives j with f j = S.
    3. h₁ shows j ∉ f j, by assuming j ∈ f j, rewriting with f j = S to get j ∉ f j, and contradiction.
    4. From h₁, j ∈ S holds by definition of S (h₂), while rewriting f j = S in h₁ gives j ∉ S (h₃).
    5. h₂ and h₃ contradict each other, which closes the goal.
