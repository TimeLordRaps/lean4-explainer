  1. def C03S06.ConvergesTo Convergence of a real sequence line 6 source

    L4DEL explanation

    A sequence converges to a if, for every positive epsilon, all terms past some index N stay within epsilon of a.

    1. The definition is ConvergesTo (s : ℕ → ℝ) (a : ℝ) := ∀ ε > 0, ∃ N, ∀ n ≥ N, |s n - a| < ε.
    2. The alternation of quantifiers matters: N may depend on ε, and n ranges over every index at least N.

    See also: C03S06.convergesTo_const

  5. theorem C03S06.convergesTo_const A constant sequence converges to its constant line 22 source

    L4DEL explanation

    Every term equals a, so the distance to a is 0, which is below any positive epsilon.

    1. intro ε εpos fixes a positive tolerance.
    2. use 0 chooses the cutoff N = 0, since all indices work.
    3. intro n nge fixes an arbitrary index.
    4. rw [sub_self, abs_zero] turns |a - a| into 0, and apply εpos closes 0 < ε.
