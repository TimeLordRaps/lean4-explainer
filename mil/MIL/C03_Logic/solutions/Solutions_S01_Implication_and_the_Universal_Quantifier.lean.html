    Bound |x*y| by |x|*|y|, then by |x|*epsilon, then by 1*epsilon, which is epsilon.

    1. intro x y ε epos ele1 xlt ylt moves the quantified variables and hypotheses into the context.
    2. First calc step |x * y| = |x| * |y| is the library lemma abs_mul.
    3. Next |x| * |y| <= |x| * ε uses mul_le_mul, with linarith and abs_nonneg closing the side goals.
    4. Then |x| * ε < 1 * ε uses mul_lt_mul_of_pos_right and linarith, using |x| < ε <= 1 and 0 < ε.
    5. The last step 1 * ε = ε is one_mul.
