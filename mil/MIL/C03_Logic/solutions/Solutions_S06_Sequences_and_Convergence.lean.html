  3. theorem C03S06.convergesTo_add The limit of a sum is the sum of the limits line 16 source

    L4DEL explanation

    Give each sequence half of the tolerance epsilon and wait until both are within their half.

    1. intro ε εpos, then have ε2pos : 0 < ε / 2 to get half the tolerance.
    2. rcases cs (ε / 2) ε2pos and rcases ct (ε / 2) ε2pos extract cutoffs Ns and Nt with their bounds hs and ht.
    3. use max Ns Nt picks a cutoff past both; for n at least that, le_of_max_le_left and le_of_max_le_right give n ≥ Ns and n ≥ Nt.
    4. A calc chain bounds |s n + t n - (a + b)| = |s n - a + (t n - b)| ≤ |s n - a| + |t n - b| < ε/2 + ε/2 = ε, using abs_add_le and add_lt_add.
    5. The matching exercise file leaves the part after use max Ns Nt as sorry; this is the solutions file version.
