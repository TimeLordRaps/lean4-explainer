  5. theorem MyRing.add_zero a + 0 = a in any ring, from commutativity and zero_add line 39 source
    Annotation provenance. AI-generated and not human-reviewed. Treat this explanatory draft as unverified and not mathematical authority.

    Swap the two summands, then use the left-identity law that is already available.

    1. The goal is a + 0 = a for an element a of a ring R.
    2. rw [add_comm] turns a + 0 into 0 + a.
    3. rw [zero_add] turns 0 + a into a, leaving a = a, which rw closes by rfl.
    4. The theorem lives in namespace MyRing so that it does not clash with the library's own add_zero; the #check lines after it show how the two names are told apart.

  11. theorem MyRing.mul_zero a * 0 = 0 via cancellation line 64 source
    Annotation provenance. AI-generated and not human-reviewed. Treat this explanatory draft as unverified and not mathematical authority.

    Show a*0 + a*0 equals a*0 + 0, then cancel one a*0 from the left.

    1. have h : a * 0 + a * 0 = a * 0 + 0 states the equation to be cancelled.
    2. Inside h, rw [← mul_add] rewrites a * 0 + a * 0 into a * (0 + 0), then two uses of add_zero remove the trailing + 0 on each side, so both sides agree.
    3. rw [add_left_cancel h] finishes the goal by cancelling the left summand.
    4. In this exercise file add_left_cancel is itself a sorry exercise, so this proof only stands once that exercise is solved; the solutions file proves it.

    See also: MyRing.add_zero
