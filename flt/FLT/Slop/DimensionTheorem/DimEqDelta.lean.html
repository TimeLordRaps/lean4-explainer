dim R = δ(R)

The Krull dimension of a Noetherian local ring equals the minimal number of generators of an ideal of definition (an 𝔪-primary ideal) — the equivalence (1) ↔ (3) of the dimension theorem (Stacks Project, tag 00KQ).

Both inequalities are assembled from Krull's height theorem and its converse, which are already in Mathlib (Mathlib/RingTheory/Ideal/KrullsHeightTheorem.lean, He–Jiang–Merten–Wang–Yang–Zhang, 2025):

  • dim R ≤ δ(R) (ringKrullDim_le_minGenPrimary): if I is an ideal of definition then 𝔪 is minimal over I (maximalIdeal_mem_minimalPrimes), so Krull's height theorem (Ideal.height_le_spanRank_toENat_of_mem_minimalPrimes) bounds dim R = height 𝔪 by the number of generators of I.
  • δ(R) ≤ dim R (minGenPrimary_le_ringKrullDim): the converse of the height theorem (Ideal.exists_spanRank_eq_and_height_eq) produces J ≤ 𝔪 generated by height 𝔪 elements with height J = height 𝔪. Every minimal prime of J then has height dim R, hence equals 𝔪, so J.radical = 𝔪: J is a system of parameters for R.

The classical proof of the second inequality constructs a system of parameters by prime avoidance (Atiyah–Macdonald, Ch. 11); here that content is packaged inside Mathlib's exists_spanRank_eq_and_height_eq.
