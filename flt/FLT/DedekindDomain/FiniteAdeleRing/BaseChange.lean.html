Base change of adele rings.

If A is a Dedekind domain with field of fractions K, if L/K is a finite separable extension and if B is the integral closure of A in L, then B is also a Dedekind domain. Hence the rings of finite adeles 𝔸_K^∞ and 𝔸_L^∞ (defined using A and B) are defined. In this file we define the natural K-algebra map 𝔸_K^∞ → 𝔸_L^∞ and the natural L-algebra map 𝔸_K^∞ ⊗[K] L → 𝔸_L^∞, and show that the latter map is an isomorphism.

Main definitions

  • FiniteAdeleRing.baseChangeAlgEquiv : L ⊗[K] 𝔸ᶠ[A, K] ≃ₐ[L] 𝔸ᶠ[B, L]

Main theorems

  • 𝔸ᶠ[B, L] has the 𝔸ᶠ[A, K]-module topology, shown as an instance.
