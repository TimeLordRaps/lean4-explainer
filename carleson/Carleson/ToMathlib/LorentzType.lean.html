    An operator has Lorentz type (p, r, q, s) if it is bounded as a map from L^{q, s} to L^{p, r}. HasLorentzType T p r q s μ ν c means that T has Lorentz type (p, r, q, s) w.r.t. measures μ, ν and constant c.
