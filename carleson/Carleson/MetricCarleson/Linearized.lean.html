  5. theorem linearized_metric_carleson Linearized metric Carleson theorem (Theorem 1.1.2) line 109 source

    Source documentation

    Theorem 1.1.2

    L4DEL explanation

    For a fixed phase choice Q, truncate the radii in an increasing family, bound each truncation, and pass to the limit by monotone convergence.

    1. Write the integral over G of the linearized operator as an increasing supremum over n of the integrals of the n-th truncation lcoConvergent.
    2. Exchange the integral and the supremum by monotone convergence (lintegral_iSup).
    3. Bound each truncated integral by the lemma R_truncation, using the L2 bound for the nontangential operators.

    Prerequisites: lcoConvergent, R_truncation
