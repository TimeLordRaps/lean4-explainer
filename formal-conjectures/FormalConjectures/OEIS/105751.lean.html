    Numerical calculation suggests that a similar division holds in this case. Type 1: primes p that do not divide any element of the sequence {$a(n)$}. In this case, unlike in A105750, the set of type 1 primes is empty; that is, every prime p divides some term of this sequence.

    Note: The triangular number n*(n+1)/2 divides $a(n)$ (see A164652). In particular, if $p$ is an odd prime then $p$ divides $a(p)$. For $p=2$, $2$ divides $a(4)=-40$.
