  2. theorem Green54.green_54 Documented declaration: green_54 sorry line 57 source

    Let $K \subset \mathbb{R}^{\mathbb{N}}$ be a balanced compact set (that is, $\lambda K \subseteq K$ whenever $|\lambda| \leq 1$) and suppose that the normalised Gaussian measure $\gamma_\infty(K) \geq 0.99$. Does the sumset $10K = K + \cdots + K$ ($10$ times) contain a compact convex set $C$ with $\gamma_\infty(C) \geq 0.01$?

    The answer is yes: Hua, Song and Tudose proved that if $\gamma_n(A) > 5/6$ then $3(A + A + A)$ contains a symmetric convex body $C$ with $\gamma_n(C) \geq 1/4$, uniformly in $n$.
