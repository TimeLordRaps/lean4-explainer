  5. def Arxiv.«2607.05739».IsIntegerValue $x_n$ takes an integer value line 57 source

    $x_n$ takes an integer value.

    Stated as $A_n \mid B_n$ rather than as ∃ m : ℤ, x n = m, so that it still says the right thing if $A_n$ were ever $0$. There $x_n$ is a pole of the tangent rather than an integer, but (B n : ℚ) / 0 is 0 in Lean and would count as one. The two agree whenever $A_n \neq 0$, which holds for every $n \leq 3000$.
