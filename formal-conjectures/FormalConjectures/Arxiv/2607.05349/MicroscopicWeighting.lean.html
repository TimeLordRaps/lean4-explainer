  3. def Arxiv.«2607.05349».weighting The weighting $\vec{w}(t) = Z(t)^{-1}\mathbf{1}$ at scale `t` line 52 source

    The weighting $\vec{w}(t) = Z(t)^{-1}\mathbf{1}$ at scale t.

    Matrix.inv is 0 on singular matrices, so this is only the intended vector where Z t is invertible. The analytic function t ↦ det (Z t) tends to 1 as t → ∞, so its zeros are isolated. Hence Z t is invertible for all small enough t > 0, as required below.

    M has finite concentration, written $\mathrm{con}(M) \neq \infty$ in the source: some gauging for M exists.

    Definition 2.4 sets $\mathrm{con}(M)$ to the concentration of any gauging, and to $\infty$ when there is none, so con(M) ≠ ∞ is exactly this.
