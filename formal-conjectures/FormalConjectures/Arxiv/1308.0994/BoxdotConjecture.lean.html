  | Atom n => σ n
  | ⊥ => ⊥
  | α ~> β => subst σ α ~> subst σ β
  | □α => □(subst σ α)

  10. structure Arxiv.«1308.0994».NormalModalLogic A “normal modal logic” L is any `Set Formula` such that: 1 line 181 source

    A “normal modal logic” L is any Set Formula such that:

    1. If K ⊢ φ, then φ ∈ L (L extends K)
    2. If φ ∈ L and (φ ~> ψ) ∈ L, then ψ ∈ L (Closed under MP)
    3. If φ ∈ L, then □φ ∈ L (Closed under Necessitation)
    4. If φ ∈ L, then φ.subst σ ∈ L for every substitution σ (Closed under Uniform Substitution)
