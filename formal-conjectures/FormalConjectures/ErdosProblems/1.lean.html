  1. abbrev Erdos1.IsSumDistinctSet Sum-distinct sets line 38 source

    A finite set of naturals $A$ is said to be a sum-distinct set for $N \in \mathbb{N}$ if $A\subseteq\{1, ..., N\}$ and the sums $\sum_{a\in S}a$ are distinct for all $S\subseteq A$

    Annotation provenance. AI-generated and not human-reviewed. Treat this explanatory draft as unverified and not mathematical authority.

    A finite set of naturals up to N is sum-distinct when no two different subsets add up to the same total.

    1. The set A must be contained in the interval from 1 to N.
    2. The map sending each subset S of A (taken from A.powerset) to its sum must be injective.

    Sources and attribution: Pinned Lean source (1646ca16afd6), Pinned project documentation, Formal Conjectures paper, arXiv v1

    Annotation provenance. AI-generated and not human-reviewed. Treat this explanatory draft as unverified and not mathematical authority.

    The statement says there is no constant C with N at least C * 2^n for every sum-distinct set of size n inside 1..N, and the file marks this as solved.

    1. The attribute reads category research solved, and the docstring says the original conjecture N >> 2^n is false because a machine-checked disproof builds sets with N / 2^n tending to zero.
    2. The formal statement is the negation of "there is C > 0 such that for all N and every sum-distinct A the inequality C * 2^|A| < N holds (for N not zero)".
    3. In this repository the proof body is sorry; the attribute points to an external formal proof at the URL it cites.

    A generalisation of the problem to sets $A \subseteq (0, N]$ of real numbers, such that the subset sums all differ by at least $1$ is proposed in [Er73] and [ErGr80].

    The positive statement is false: every natural-number counterexample to erdos_1 embeds into $\mathbb{R}$, and distinct integer subset sums differ by at least one.

    [ErGr80] Erdős, P. and Graham, R., Old and new problems and results in combinatorial number theory. Monographies de L'Enseignement Mathematique (1980).
