  3. theorem Erdos44.erdos_44.variants.empty_start The case where we start with an empty set (constructing large Sidon sets) sorry line 106 source

    The case where we start with an empty set (constructing large Sidon sets).

    The answer is yes. Singer [Si38] constructed Sidon sets of size $q + 1$ in $\{1, \ldots, q^2 + q + 1\}$ for every prime $q$. Since $p_{n+1}/p_n \to 1$ for consecutive primes, this gives Sidon sets of size $(1 - o(1))M^{1/2}$ in $\{1, \ldots, M\}$ for every $M$; see erdosproblems.com/30.
