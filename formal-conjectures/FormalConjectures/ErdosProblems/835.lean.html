  7. def Erdos835.johnsonBound Johnson's upper bound on the maximum size `A(n, d, w)` of a `n`-dimensional binary code of distance `d` and weight `w` is as follows: * If `d > 2 * w`, then `A(n, d, w) = 1` line 95 source

    Johnson's upper bound on the maximum size A(n, d, w) of a n-dimensional binary code of distance d and weight w is as follows:

    • If d > 2 * w, then A(n, d, w) = 1.
    • If d ≤ 2 * w, then A(n, d, w) ≤ ⌊n / w * A(n - 1, d, w - 1)⌋.
    Annotation provenance. AI-generated and not human-reviewed. Treat this explanatory draft as unverified and not mathematical authority.

    Johnson's upper bound on the maximum size `A(n, d, w)` of a `n`-dimensional binary code of distance `d` and weight `w` is as follows: * If `d > 2 * w`, then `A(n, d, w) = 1`. * If `d ≤ 2 * w`, then `A(n, d, w) ≤ ⌊n / w * A(n - 1, d, w - 1)⌋`.

    def johnsonBound : ℕ → ℕ → ℕ → ℕ
  | 0, _d, _w => 1
  | _n, _d, 0 => 1
  | n + 1, d, w + 1 => if 2 * (w + 1) < d then 1 else (n + 1) * johnsonBound n d w / (w + 1)
