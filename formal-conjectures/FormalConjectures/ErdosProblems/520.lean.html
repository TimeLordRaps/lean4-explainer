    A random function $f$ is Rademacher multiplicative if $f(1) = 1$, for each prime $p$, we independently choose $f(p) \in \{-1, 1\}$ uniformly at random (so each $f(p)$ is a measurable function of the sample point), for each square-free integer $n = p_1 \cdots p_r$, $f(n) = f(p_1) \cdots f(p_r)$, and for each non-squarefree integer $n$, $f(n) = 0$.
