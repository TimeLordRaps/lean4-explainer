  5. theorem Erdos1099.erdos_1099.variants.ratio_sum Erdős remarks that this problem occurred to him when considering $\sum_i \frac{d_{i+1}}{d_i}$ sorry line 90 source

    Source documentation

    Erdős remarks that this problem occurred to him when considering $\sum_i \frac{d_{i+1}}{d_i}$. It is easy to see that $\sum_{i} \frac{d_{i+1}}{d_i}> \tau(n)+\log n$, and Erdős asked whether $$\liminf \left(\sum_{i} \frac{d_{i+1}}{d_i}-\tau(n)-\log n\right)<\infty,$$ which follows from the affirmative answer to the main question.
