  1. theorem Erdos3.erdos_3 Erdos Problem 3: divergent reciprocal sums and arithmetic progressions sorry line 47 source

    Source documentation

    If $A \subset \mathbb{N}$ has $\sum_{n \in A}\frac 1 n = \infty$, then must $A$ contain arbitrarily long arithmetic progressions?

    L4DEL explanation

    If the reciprocals of a set of naturals sum to infinity, must the set contain arithmetic progressions of every length? The file marks this as open.

    1. The attribute reads category research open, and the statement is written as "answer(sorry) iff ...", so the yes-or-no answer itself is left unfilled.
    2. The right-hand side says: for every set A of naturals whose reciprocal sum is not summable, there are arbitrarily large k (infinitely often in k) with a subset S of A that is an arithmetic progression of length k.
    3. The proof body is sorry, as for the other open problems in the repository.
