    A set A : Set ℕ is said to have property P₁ if for any nonconstant sequence f : A → {-1, 1}, one can always select a finite, nonempty subset S ⊆ A \ {0} such that ∑ n ∈ S, fₙ / n = 0. This is defined in [Sa82b].

  5. theorem Erdos318.erdos_318.variants.contain_single_even For any infinite set A containing exactly one positive even number, A does not have property P₁ sorry line 112 source

    Source documentation

    For any infinite set A containing exactly one positive even number, A does not have property P₁. Sattler [Sa82] credits this observation to Erdős, who presumably found this after [ErGr80]. The element 0 is not counted, since P₁ ignores it, and the infinitude hypothesis excludes degenerate sets such as {2}, on which P₁ holds vacuously.
