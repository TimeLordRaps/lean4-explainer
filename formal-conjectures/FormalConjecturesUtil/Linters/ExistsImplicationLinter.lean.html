The Exists Implication Linter

Many misformalisations stem from using a pattern of the form ∃ x, P x → Q instead of ∃ x, P x ∧ Q (e.g. when formalising something of the form "there is positive x such that ..."). This is almost always incorrect (and trivial to prove) since it then suffices to pick an x that does not satisfy P. This linter flags occurrences of this pattern to the user and proposes a corrected syntax.
