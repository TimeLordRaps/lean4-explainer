The Module Docstring Linter

This file implements a linter that enforces module docstring hygiene:

  1. Missing module docstring: warns when a file has no /-! ... -/ block at all (detected on the first non-moduleDoc command).
  2. Duplicate module docstrings: warns when a file has more than one /-! ... -/ block (subsequent blocks should be regular /- ... -/ comments).
