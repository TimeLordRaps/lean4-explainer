Gromov hyperbolic pseudometric spaces

This is being upstreamed to Mathlib in leanprover-community/mathlib4#43723.

TODO: delete this file when this repository moves to a Mathlib version that contains it.

Main definitions

  • Metric.IsHyperbolicWith: A pseudometric space is hyperbolic with constant δ if and only if for all w x y z the four-point condition min (gromovProduct w x y) (gromovProduct w y z) - δ ≤ gromovProduct w x z holds.
  • Metric.IsHyperbolic: A pseudometric space is hyperbolic if it is δ-hyperbolic for some constant δ.

Main results

  • Metric.isHyperbolicWith_diam_univ: A bounded space is δ-hyperbolic with respect to its diameter.

Implementation notes

The constant δ in IsHyperbolicWith X δ is a real number. For a non-empty space, taking w = x = y = z in the four-point condition yields 0 ≤ δ.
