Ramsey-type properties of graph pairs

The Erdős–Hajnal "exceptional pair" trio of predicates:

  • HasFiniteRamseyProperty G₁ G₂ — for every n ≥ 1 there is a G₁-free graph H such that every n-edge-colouring of H contains a monochromatic G₂.
  • HasCountableRamseyEscape G₁ G₂ — every G₁-free graph H admits a countable edge-colouring with every colour class G₂-free.
  • IsErdosHajnalExceptional G₁ G₂ — the conjunction of both.

These were introduced for Erdős Problem 596 but are reusable for Problem 595 and other Ramsey-type questions; we factor them out per mo271's review.

It also defines the two-colour graph Ramsey number graphRamsey G H and the notion of a Ramsey size linear graph IsRamseySizeLinear G of Erdős, Faudree, Rousseau and Schelp.

References

  • Erdős, Faudree, Rousseau and Schelp, Ramsey size linear graphs, Combin. Probab. Comput. 2 (1993), 389–399.

  8. def SimpleGraph.IsRamseySizeLinear Documented declaration: IsRamseySizeLinear line 111 source

    A graph G is Ramsey size linear if there exists a constant c > 0 such that for all graphs H with m edges and no isolated vertices, the Ramsey number satisfies R(G, H) ≤ c · m.

    Note that this is about the (vertex) Ramsey number graphRamsey G H, not the size Ramsey number sizeRamsey G H.

    Annotation provenance. AI-generated and not human-reviewed. Treat this explanatory draft as unverified and not mathematical authority.
