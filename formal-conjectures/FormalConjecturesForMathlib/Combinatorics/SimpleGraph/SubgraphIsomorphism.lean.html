    The number of distinct unique subgraphs of H: the number of isomorphism classes of graphs that occur exactly once as a subgraph of H. Each such class contains exactly one subgraph G ≤ H (uniqueness forbids a second isomorphic copy), so counting those representatives counts the classes.
