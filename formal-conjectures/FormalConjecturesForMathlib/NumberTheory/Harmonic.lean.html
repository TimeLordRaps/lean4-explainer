Block harmonic sums

Mathlib's harmonic n is the initial harmonic sum ∑_{1 ≤ k ≤ n} 1 / k. Several problems instead need the block sum ∑_{n ≤ k ≤ m} 1 / k, which is what harmonicBlock gives. Like harmonic it is valued in ℚ; cast at the use site when a real value is wanted.

Main definitions

  • harmonicBlock: the block harmonic sum ∑_{n ≤ k ≤ m} 1 / k.

Main results

  • harmonicBlock_eq_zero_of_lt: the block sum is empty when m < n.
  • harmonicBlock_one: harmonicBlock 1 n is Mathlib's harmonic n.
