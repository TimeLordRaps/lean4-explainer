The real and complex periods of an elliptic curve as integrals

Let $E$ be an elliptic curve with Weierstrass equation $y^2 + a_1 xy + a_3 y = x^3 + a_2 x^2 + a_4 x + a_6$ and invariant differential $\omega = \frac{dx}{2y + a_1 x + a_3}$. Completing the square, $(2y + a_1 x + a_3)^2 = 4x^3 + b_2 x^2 + 2 b_4 x + b_6 =: F(x)$, the 2-division polynomial WeierstrassCurve.Ψ₂Sq, so $|\omega| = |dx| / \sqrt{|F(x)|}$ on the $x$-line.

  • Over $\mathbb{R}$ (a curve W : WeierstrassCurve ℝ), the real locus $E(\mathbb{R})$ lies over $\{F \geq 0\}$ with two branches $2y + a_1 x + a_3 = \pm\sqrt{F(x)}$, so the real period is $\Omega_{\mathbb{R}} = \int_{E(\mathbb{R})} |\omega| = 2 \int_{\mathbb{R}} dx / \sqrt{F(x)}$ (WeierstrassCurve.realPeriod).
  • Over $\mathbb{C}$ (a curve W : WeierstrassCurve ℂ), the $x$-coordinate is a double cover $E(\mathbb{C}) \to \mathbb{P}^1(\mathbb{C})$ and $|\omega \wedge \bar\omega| = 4\, dA(x) / |F(x)|$ on each sheet, so the complex period is $\Omega_{\mathbb{C}} = \int_{E(\mathbb{C})} |\omega \wedge \bar\omega| = 4 \int_{\mathbb{C}} dA(x) / |F(x)|$ (WeierstrassCurve.complexPeriod).
