Hyperbolic groups

A finitely generated group is hyperbolic if its induced metric space with respect to a chosen family of Group.Generators satisfies the Gromov hyperbolicity condition.

This is being upstreamed to Mathlib in leanprover-community/mathlib4#44339.

TODO: delete this file when this repository moves to a Mathlib version that contains it.

Main definitions

  • Group.Generators.IsHyperbolicWith: A group is δ-hyperbolic with respect to a generating family P if its induced metric space is δ-hyperbolic.
  • Group.IsHyperbolic: A group G is hyperbolic if there exists a finite generating family P and a constant δ such that G is δ-hyperbolic with respect to P.

Main results

  • [Group.IsHyperbolic G] : Group.FG G: Every hyperbolic group is finitely generated.
  • [Finite G] : Group.IsHyperbolic G: Every finite group is hyperbolic.

Implementation notes

The hyperbolicity condition applies directly to the word metric, without requiring the Cayley graph.
