  7. def ComplexityTheory.NP Documented declaration: NP line 93 source

    The class NP is the set of decision problems $L$ such that there exists a polynomial $p$ over ℕ and a poly-time Turing machine computing a relation $R$ where for all $x$, $L(x)$ iff there exists a $w$ of length at most $p (|x|)$ such that $R(x,w)$ accepts.

    See Definition 2.1 in Arora-Barak (2009).

  9. def ComplexityTheory.BPP Documented declaration: BPP line 114 source

    The class BPP is the set of decision problems $L$ such that there exists a polynomial $p$ over ℕ and a poly-time Turing machine computing a relation $R$ where for all $x$, a uniformly random string $r$ of length $p (|x|)$ satisfies $R (x, r) = L (x)$ with probability at least $2/3$.

    See Definition 7.4 in Arora-Barak (2009), or Antonelli et al. (2024).
