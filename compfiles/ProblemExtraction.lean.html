ProblemExtraction.lean

1 declarations, 0 contain sorry, 0 axioms

Special commands to aid in "problem extraction".

For the math problems that we archive, we aim to include proofs in-line. Sometimes, however, we want to present the problems without giving away information about the solutions. Therefore, we have "problem extraction" -- a means of stripping solutions.

During problem extraction, all declarations are removed except those that have been tagged with one of the below command wrappers.
