International Mathematical Olympiad 1985, Problem 6

For every real number x_1, construct the sequence {x_1,x_2, ...} by setting x_{n+1} = x_n * (x_n + 1 / n) for each n >= 1.

Prove that there exists exactly one value of x_1 for which 0 < x_n , x_n < x_{n+1}, and x_{n+1} < 1 for every n.
