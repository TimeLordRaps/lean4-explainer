International Mathematical Olympiad 2011, Problem 1

Given any set A = {a₁, a₂, a₃, a₄} of four distinct positive integers, we denote the sum a₁ + a₂ + a₃ + a₄ by s_A. Let n_A denote the number of pairs (i, j) with 1 ≤ i < j ≤ 4 for which a_i + a_j divides s_A. Find all sets A of four distinct positive integers which achieve the largest possible value of n_A.
