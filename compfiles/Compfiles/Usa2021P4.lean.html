USA Mathematical Olympiad 2021, Problem 4

A finite set S of positive integers has the property that, for each s ∈ S, and each positive integer divisor d of s, there exists a unique element t ∈ S satisfying gcd(s, t) = d. (The elements s and t could be equal.)

Given this information, find all possible values for the number of elements of S.
