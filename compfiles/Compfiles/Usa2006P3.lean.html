USA Mathematical Olympiad 2006, Problem 3

For integral m, let p(m) be the greatest prime divisor of m. By convention, we set p(±1) = 1 and p(0) = ∞. Find all polynomials f with integer coefficients such that the sequence

{p(f(n²)) − 2n}, n = 0, 1, 2, ...

is bounded above. (In particular, this requires f(n²) ≠ 0 for n ≥ 0.)

    If f is nonconstant and satisfies the prime bound, then f has a root of the form (2k+1)²/4 over ℚ. This is the heart of the proof: a large prime q dividing f(n²) forces q = 2n + 2k + 1 with k ≤ B, and then q divides Fs f (2k+1); since there are infinitely many such primes but only finitely many possible k, some Fs f (2k+1) vanishes.
