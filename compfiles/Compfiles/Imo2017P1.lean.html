International Mathematical Olympiad 2017, Problem 1

For any integer a₀ > 1, define the sequence

aₙ₊₁ = √aₙ, if aₙ is a perfect square or aₙ + 3 otherwise.

Find all values of a₀ for which there exists A such that aₙ = A for infinitely many values of n.
