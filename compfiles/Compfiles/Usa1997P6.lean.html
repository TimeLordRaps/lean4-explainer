USA Mathematical Olympiad 1997, Problem 6

Suppose the sequence of nonnegative integers a₁, a₂, ..., a₁₉₉₇ satisfies

aᵢ + aⱼ ≤ aᵢ₊ⱼ ≤ aᵢ + aⱼ + 1

for all i, j ≥ 1 with i + j ≤ 1997. Prove that there exists a real number x such that aₙ = ⌊nx⌋ for all 1 ≤ n ≤ 1997.
