Which m × n rectangles can be tiled by hooks?

  22. lemma Imo2004P3.pair_check The key local fact line 168 source

    Source documentation

    The key local fact. Suppose two disjoint hooks are such that the hole of the first one is covered by the second one, and moreover the hole of the second hook is either covered by the first hook or can be covered by a third hook disjoint from both (as must happen in any tiling of a rectangle). Then the hole of the second hook is covered by the first, and the union of the two hooks is one of the six tiles. (Checked case by case.)

    lemma pair_check :
    ∀ σ₁ ∈ hookShapes, ∀ σ₂ ∈ hookShapes,
      ∀ t ∈ (σ₂.image fun c => (1, 1) - c),
        Disjoint σ₁ (σ₂.image (· + t)) →
          ((1, 1) + t ∈ σ₁ ∨
            0 < (hookShapes.biUnion fun σ₃ =>

                Disjoint (σ₃.image (· + t₃)) (σ₁ ∪ (σ₂.image (· + t)))).card) →
          ((1, 1) + t ∈ σ₁) ∧
            0 < (tileShapes.filter fun τ =>
              σ₁ ∪ (σ₂.image (· + t)) =
