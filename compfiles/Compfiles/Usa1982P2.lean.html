USA Mathematical Olympiad 1982, Problem 2

Show that if m, n are positive integers such that (x^(m+n) + y^(m+n) + z^(m+n))/(m+n) = ((x^m + y^m + z^m)/m) ((x^n + y^n + z^n)/n) for all real x, y, z with sum 0, then {m, n} = {2, 3} or {2, 5}.
