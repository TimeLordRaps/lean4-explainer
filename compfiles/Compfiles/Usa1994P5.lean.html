USA Mathematical Olympiad 1994, Problem 5

Let |U|, σ(U) and π(U) denote the number of elements, the sum, and the product, respectively, of a finite set U of positive integers. (If U is the empty set, |U| = 0, σ(U) = 0, π(U) = 1.) Let S be a finite set of positive integers. As usual, we define (n k) = n! / (k! (n-k)!) for 0 ≤ k ≤ n and (n k) = 0 otherwise. Prove that

∑_{U ⊆ S} (-1)^{|U|} (m - σ(U) choose |S|) = π(S)

for all integers m ≥ σ(S).
