    The key gap lemma: writing s j for the sum of the j smallest elements, if s j < 1500 then the next element satisfies a j ≤ s j + 1. Indeed, s j + 1 ≤ 1500 must occur as a subset sum, and any subset with that sum must contain some a i with i ≥ j, so a j ≤ a i ≤ s j + 1.
