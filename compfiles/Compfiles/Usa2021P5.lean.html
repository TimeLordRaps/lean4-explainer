USA Mathematical Olympiad 2021, Problem 5

Let n ≥ 4 be an integer. Find all positive real solutions to the following system of 2n equations:

a₁ = 1/a₂ₙ + 1/a₂, a₂ = a₁ + a₃, a₃ = 1/a₂ + 1/a₄, a₄ = a₃ + a₅, a₅ = 1/a₄ + 1/a₆, a₆ = a₅ + a₇, ⋮ a₂ₙ₋₁ = 1/a₂ₙ₋₂ + 1/a₂ₙ, a₂ₙ = a₂ₙ₋₁ + a₁.
