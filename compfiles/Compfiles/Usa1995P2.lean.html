USA Mathematical Olympiad 1995, Problem 2

A trigonometric map is any one of sin, cos, tan, arcsin, arccos and arctan. Show that given any positive rational number x, one can find a finite sequence of trigonometric maps which take 0 to x. [So we need to show that we can always find a sequence of trigonometric maps tᵢ so that: x₁ = t₀(0), x₂ = t₁(x₁), ..., xₙ = tₙ₋₁(xₙ₋₁), x = tₙ(xₙ).]

  9. lemma Usa1995P2.reachable_sqrt_div Every number of the form √(m / n) with m, n positive naturals can be reached from 0 by a finite sequence of trigonometric maps line 94 source

    Source documentation

    Every number of the form √(m / n) with m, n positive naturals can be reached from 0 by a finite sequence of trigonometric maps. Proof by well-founded induction on m + n (Euclidean algorithm):

    • if m = n then √(m/n) = 1 = cos 0;
    • if m > n then √(m/n) = √(1 + (√((m-n)/n))²) and (m-n) + n < m + n;
    • if m < n then √(m/n) = 1 / √(n/m) and √(n/m) = √(1 + (√((n-m)/m))²) with (n-m) + m < m + n.
