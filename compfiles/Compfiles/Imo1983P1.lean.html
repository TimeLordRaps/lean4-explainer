International Mathematical Olympiad 1983, Problem 1

Let ℝ+ be the set of positive real numbers.

Determine all functions f : ℝ+ → ℝ+ which satisfy: i) f(xf(y)) = yf(x) for all x y ∈ ℝ+. ii) f(x) → 0 as x → ∞.
