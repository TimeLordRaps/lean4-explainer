International Mathematical Olympiad 1978, Problem 3

The set of all positive integers is the union of two disjoint subsets {f(1), f(2), ..., f(n), ...} and {g(1), g(2), ..., g(n), ...}, where

f(1) < f(2) < ... < f(n) < ..., g(1) < g(2) < ... < g(n) < ...,

and g(n) = f(f(n)) + 1 for all n ≥ 1.
