USA Mathematical Olympiad 1974, Problem 4

A, B, C play a series of games. Each game is between two players. The next game is between the winner and the person who was not playing. The series continues until one player has won two games. He wins the series. A is the weakest player, C the strongest. Each player has a fixed probability of winning against a given opponent. A chooses who plays the first game. Show that he should choose to play himself against B.

  3. def Usa1974P4.probWinA Documented declaration: probWinA line 59 source

    Source documentation

    The probability that player A wins the series, where

    • win x y is the probability that x beats y in a single game,
    • the next game is played between w (the winner of the previous game) and i (the player who sat out the previous game); the loser of a game sits out the next one,
    • hist is the list of winners of the games played so far, and
    • n is a fuel bounding the number of games still to be played.

    The series ends as soon as some player has won two games in total, so it lasts at most four games: if no one has won twice after three games then the three winners so far are three distinct players, and the fourth game is played between two of them, so its winner reaches two wins.

    standard axioms: Classical.choice, Quot.sound, propext what this means

    def probWinA (win : Player → Player → ℝ) :
    ℕ → Player → Player → List Player → ℝ
  | 0, _, _, _ => 0
  | n + 1, w, i, hist =>
      win w i * (if w ∈ hist then (if w = .A then 1 else 0)
                 else probWinA win n w (third w i) (w :: hist)) +
      win i w * (if i ∈ hist then (if i = .A then 1 else 0)
                 else probWinA win n i (third w i) (i :: hist))
