USA Mathematical Olympiad 2007, Problem 1

Let n be a positive integer. Define a sequence by setting a₁ = n and, for each k > 1, letting aₖ be the unique integer in the range 0 ≤ aₖ ≤ k - 1 for which a₁ + a₂ + ··· + aₖ is divisible by k. (For instance, when n = 9 the obtained sequence is 9, 1, 2, 0, 3, 3, 3, ....) Prove that for any n the sequence a₁, a₂, ... eventually becomes constant.
