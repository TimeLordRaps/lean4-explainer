USA Mathematical Olympiad 2012, Problem 6

For integer n ≥ 2, let x₁, x₂, ..., xₙ be real numbers satisfying x₁ + x₂ + ... + xₙ = 0 and x₁² + x₂² + ... + xₙ² = 1. For each subset A ⊆ {1, 2, ..., n}, define S_A = ∑_{i ∈ A} x_i. (If A is the empty set, then S_A = 0.) Prove that for any positive number λ, the number of sets A satisfying S_A ≥ λ is at most 2^(n-3)/λ². For which choices of x₁, x₂, ..., xₙ, λ does equality hold?
