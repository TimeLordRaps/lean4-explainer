USA Mathematical Olympiad 2023, Problem 5

Let n be an integer greater than 2. We will be arranging the numbers 1, 2, ... n² into an n × n grid. Such an arrangement is called row-valid if the numbers in each row can be permuted to make an arithmetic progression. Similarly, such an arrangement is called column-valid if the numbers in each column can be permuted to make an arithmetic progression.

Determine the values of n for which it possible to transform any row-valid arrangement into a column-valid arrangement by permuting the numbers in each row.
