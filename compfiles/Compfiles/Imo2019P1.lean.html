  3. problem Imo2019P1.imo2019_p1 IMO 2019 Problem 1: a functional equation on the integers line 41 source

    L4DEL explanation

    The integer functions with f(2a) + 2f(b) = f(f(a+b)) are exactly the zero function and f(z) = 2z + c.

    1. Problem: determine all f from the integers to the integers with f(2a) + 2f(b) = f(f(a+b)) for all integers a, b. The formal answer is the determined set solution_set = zero function or z to 2z + c for some integer c, and the theorem says f satisfies the equation iff f is in that set.
    2. Solution (complete, no sorry): the reverse direction is a direct computation.
    3. Forward direction: g(z) = f(z) - f(0) is additive, hence linear g(z) = d * z (lemma additive_to_int_linear), so f(z) = d * z + f(0).
    4. Substituting back into the equation splits into d = 0, which forces f(0) = 0 and so f = 0, and d not 0, which ends with f(z) = 2z + f(0), so f(0) is the free constant.
