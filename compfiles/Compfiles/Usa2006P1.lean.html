USA Mathematical Olympiad 2006, Problem 1

Let p be a prime number and let s be an integer with 0 < s < p. Prove that there exist integers m and n with 0 < m < n < p and

{sm/p} < {sn/p} < s/p,

where {x} = x − ⌊x⌋ denotes the fractional part of x, if and only if s is not a divisor of p − 1.
