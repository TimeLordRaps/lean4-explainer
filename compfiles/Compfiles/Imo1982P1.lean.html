International Mathematical Olympiad 1982, Problem 1

Let f be a function from positive integers to nonnegative integers such that

  1. f(2) = 0
  2. f(3) > 0
  3. f(9999) = 3333
  4. for all m,n > 0, f (m + n) - f (m) - f(n) = 1 or 0

Determine the value of f(1982).
