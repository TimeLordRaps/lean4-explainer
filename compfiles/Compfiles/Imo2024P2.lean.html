    The only pair of positive integers (a, b) for which gcd(a^n + b, b^n + a) is eventually constant is (1, 1).

    1. Problem: determine all pairs of positive integers (a, b) such that gcd(a^n + b, b^n + a) takes one constant value g for all n at least some N. The formal answer is solutionSet = {(1, 1)}, stated as membership in solutionSet iff such g and N exist.
    2. Solution (complete, no sorry; imported from the Mathlib Archive per the file header): for (1, 1) every term is gcd(2, 2) = 2, so g = 2 and N = 1 work.
    3. Conversely, the file works modulo ab+1: for exponents congruent to -1 modulo phi(ab+1) the terms vanish modulo ab+1, so ab+1 divides g and all large terms, hence all terms, which forces a = b = 1.
