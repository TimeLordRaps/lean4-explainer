The homomorphism form of PFR

Here we apply (improved) PFR to show that approximate homomorphisms f from a 2-group to a 2-group are close to actual homomorphisms. Here, approximate is in the sense that f(x+y)-f(x)-f(y) takes few values.

Main results

  • goursat: A convenient description of the subspaces of $G \times G'$ when $G, G'$ are elementary abelian 2-groups.
  • homomorphism_pfr : If $f : G → G'$ is a map between finite abelian elementary 2-groups such that $f(x+y)-f(x)-f(y)$ takes at most $K$ values, then there is a homomorphism $\phi: G \to G'$ such that $f(x)-\phi(x)$ takes at most $K^{10}$ values.

  3. theorem homomorphism_pfr Homomorphism PFR line 75 source

    Source documentation

    Let $f: G \to G'$ be a function, and let $S$ denote the set $$ S := \{ f(x+y)-f(x)-f(y): x,y \in G \}.$$ Then there exists a homomorphism $\phi: G \to G'$ such that $$ |\{f(x) - \phi(x)\}| \leq |S|^{10}. $$

    L4DEL explanation

    A map between F2-vector spaces that is almost additive differs from a true homomorphism by a set of size at most |S|^10.

    1. Statement: if f(x+y) - f(x) - f(y) always lies in a set S, there are a group homomorphism phi and a set T with |T| at most |S|^10 such that f(x) - phi(x) lies in T for all x.
    2. Consider the graph A of f inside G x G'. Then A + A sits inside A - ({0} x S), so |A + A| is at most |S| |A|.
    3. Apply a PFR covering lemma (better_PFR_conjecture_aux) to get a subgroup H of G x G' and a covering set c of A.
    4. Use Goursat's lemma (goursat) to describe H as a graph-like subgroup over phi, then take T as the image of c + ({0} x H1) under the map (x, y) to y - phi(x).

    Prerequisites: goursat

    See also: PFR_conjecture
