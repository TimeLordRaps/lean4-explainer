lean4-explainer showcase

What lean4-explainer produces for the Lean projects below. Hosted annotations, when present, carry their provenance and source grounding beside the explanation. To write your own explanations, start with the Lean4 Domain Explanation Language (L4DEL) guide or the README.

This release includes Lean-backed trust results produced locally. A cached result is reused only for matching source, declarations, Lean toolchain, probe, and dependency pins. Each corpus's Trust page identifies checked declarations and every file that remained UNKNOWN. The corpus-card sorry count is still a separate textual source scan.

Annotation grounding audit (JSON): generated wording is checked against pinned source text; curated wording remains source-linked and unreviewed.

OpenAI/math and AlphaProof Nexus explanations

Search and read the formal mathematics by theorem, topic, module, or source file. The site separates checked Lean evidence, source-derived wording, and unreviewed annotation prose.

  • OpenAI/math explanations — browse plain-language, source-linked explanations of the pinned OpenAI mathematics formalizations.
  • AlphaProof Nexus explanations — explore Google DeepMind's published Lean 4 proof artifacts with local trust checks and pinned provenance.
